# Header Layout Guidelines - Finance Page

Tujuan utama adalah membuat halaman dashboard keuangan terasa seperti aplikasi modern (Linear, Vercel, Arc Browser, Notion), bukan dashboard admin tradisional.

## Layout

Header harus menggunakan layout dua kolom.

Kolom kiri berisi:

- Judul halaman
- Deskripsi singkat

Kolom kanan berisi:

- Date Range Picker
- Tombol Tambah Transaksi

Semua elemen harus sejajar secara vertikal.

Jangan menempatkan judul di tengah halaman.

---

## Hierarchy

Urutan visual harus:

1. Nama halaman kecil (opsional)
2. Judul besar
3. Deskripsi
4. Action
5. Summary Card

Summary Card harus terasa menjadi bagian dari header, bukan section yang terpisah.

---

## Spacing

Gunakan spacing yang konsisten.

Header ke Summary Card:

24–32px

Judul ke Subtitle:

6–8px

Subtitle ke Card:

24px

Card ke Tab:

20px

Tab ke Chart:

20px

Hindari whitespace yang terlalu besar.

---

## CTA

Date Picker dan Tombol Tambah Transaksi merupakan satu kelompok action.

Desktop:

[ Date Picker ] [ Tambah Transaksi ]

Mobile:

Date Picker
Tambah Transaksi

Gunakan gap sekitar 12–16px.

---

## Summary Card

Card harus sedikit lebih tinggi agar informasi terasa penting.

Target tinggi:

140–160px

Gunakan padding besar (24px).

Tambahkan:

- Icon
- Nilai utama
- Persentase perubahan
- Warna status

---

## Container

Dashboard tidak boleh terlalu sempit.

Gunakan max-width sekitar 1360–1440px agar ruang kosong di monitor desktop tidak berlebihan.

---

## Visual Style

Pertahankan gaya:

- Minimalis
- Banyak whitespace tetapi tetap seimbang
- Border tipis (#E5E7EB)
- Radius 16px
- Shadow sangat halus
- Typography modern
- Fokus pada keterbacaan

Jangan menggunakan warna mencolok atau dekorasi yang tidak perlu.

Setiap perubahan layout harus mengutamakan:
- keseimbangan visual,
- hierarki informasi,
- efisiensi ruang,
- dan pengalaman pengguna saat memindai informasi secara cepat.
